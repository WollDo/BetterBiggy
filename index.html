What it does

Everything you wished the site had

BetterBiggy layers on top of LittleBiggy without touching your account or data. Just load it and the site improves.

🌙

Dark theme

Full site overhaul — dark backgrounds, readable typography, consistent orange accents throughout.

₿

Currency conversion

BTC prices converted to your local currency in real time using live rates from CoinGecko and Frankfurter. 30+ currencies supported.

⚡

Works as you scroll

Prices convert as new listings load on the infinite scroll listing pages — nothing slips through.

🔍

Better search

Click directly on the keyword search box without having to click the button first. Small thing, big difference.

🔒

No data collected

Runs entirely in your browser. No accounts, no tracking, no requests to any server except live rate APIs.

🔹

Open source

All code is public on GitHub. Read it, fork it, suggest features — it's yours to inspect and build on.

Installation

Up in under a minute

Chrome doesn't allow free extensions outside the store, so you load it manually. It's a one-time thing.

1

Download the extension

Click the download button above, or go to the GitHub repo and hit Code → Download ZIP.

2

Extract the ZIP

Unzip the downloaded file anywhere on your machine.

3

Enable developer mode in Chrome

Go to chrome://extensions and toggle Developer mode on in the top right corner.

4

Load the folder

Click Load unpacked and select the BetterBiggy-src folder inside the extracted ZIP. BetterBiggy will appear in your extensions list immediately.

5

Pin it and pick your currency

Click the puzzle piece icon in the Chrome toolbar, pin BetterBiggy, then open it and choose your local currency. Done.
